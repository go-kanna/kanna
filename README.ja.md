# kanna

[![English](https://img.shields.io/badge/lang-English-blue.svg)](README.md)

[kanna](https://go-kanna.github.io/ja/) コードジェネレータファミリーの `kanna` コマンドです。まだ設計中で、ここにリリース済みのものはありません。それまでは、サイトの各ページのとおり、ジェネレータを個別に実行してください。

## ファミリーの開発

[`DEVELOPING.md`](DEVELOPING.md) には、複数のリポジトリにまたがる変更のしかたを書いています。[`dev`](dev) にある全チェックアウトのワークスペース、それに対して全リポジトリのテストを実行するスクリプト、リリースの順序です。

## このモジュールの以前のバージョン

`github.com/go-kanna/kanna` は、以前は別のモジュール（kanna v0.2.x と初代の kanna-orm）でした。そのバージョン v0.0.1 から v0.2.0 は Go モジュールプロキシに残り、コードはサイトのリポジトリの [`archive/v0.2`](https://github.com/go-kanna/go-kanna.github.io/tree/archive/v0.2) ブランチにあります。`kanna` コマンドは、それより上の v0.3.0 以降から始まります。
